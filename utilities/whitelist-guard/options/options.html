🛡️ 화이트리스트 가드 — 설정

아마존 신고 페이지에서 고객사 공식 판매처를 자동으로 걸러 오신고를 막습니다.

1. 처음 설정하는 방법

  1. 팀 허브 → 관리자 → 화이트리스트 셀러 관리 로 이동
  2. 페이지 맨 아래 크롬 확장 연결 에서 토큰 발급 클릭
  3. 표시된 토큰을 복사해 아래에 붙여넣고 저장 후 동기화

토큰은 발급 직후에만 보입니다. 분실하면 허브에서 새로 발급하면 됩니다.
