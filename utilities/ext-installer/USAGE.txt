MYRIAD 확장 프로그램 설치 도우미 - 사용법
==========================================

[처음 한 번]
1. MYRIAD_Extension_Installer.exe 를 두 번 클릭해 실행합니다.
   - "Windows 의 PC 보호" 파란 창이 뜨면 → [추가 정보] → [실행] 을 누르세요.
     (회사 자체 제작 프로그램이라 나오는 안내이며, 한 번만 뜹니다)
2. 프로그램이 최신 파일을 내려받고, 오른쪽에 그림 안내가 나옵니다.
3. [크롬 확장 페이지 열기] 버튼을 누른 뒤 크롬에서 순서대로:
   (1) 우측 상단 「개발자 모드」 켜기
   (2) 「압축해제된 확장 프로그램을 로드합니다」 클릭
   (3) 폴더 창이 뜨면 Ctrl+V 누르고 Enter
   → 왼쪽 목록의 동그라미가 초록색 체크로 바뀌면 성공입니다.
4. 등록할 확장이 2개면 3번을 한 번 더 반복합니다. (경로는 자동으로 다시 복사됩니다)

[그 다음부터]
- PC 를 켤 때 자동으로 새 버전을 확인합니다. 새 버전이 있으면 창이 뜨고
  [지금 크롬 다시 열기] 만 누르면 끝입니다. 아무 변화가 없으면 창이 뜨지 않습니다.
- 직접 확인하려면 EXE 를 다시 실행하면 됩니다. 몇 번을 실행해도 안전합니다.

[문제가 있을 때]
- 로그 파일: %LOCALAPPDATA%\Myriad\ExtInstaller\installer.log
- 확장 파일 위치: %LOCALAPPDATA%\Myriad\Extensions\
- 담당자에게 로그 파일을 보내 주세요.
