# 공용 PC 원격 접속 세팅 (Phase 24)

팀 공용 노트북(Win11 Pro)에 실무자들이 원격 데스크톱으로 접속하기 위한 1회 세팅.

## 전제
- Win11 Pro 원격 데스크톱은 **화면 1명만** 가능. 다른 사람이 접속하면 기존 사람 화면이 끊김(작업은 백그라운드 유지).
- 실무자별 윈도우 계정 + 각자 본인 허브 토큰으로 런처 설치 → 허브 '실행할 PC' 에서 `공용노트북(본인)` 선택.

## 순서 (공용 노트북에서)
1. 공용 노트북에 **최신 런처**(v2026-10-12 이상) 설치 + MyriadSetup 으로 토큰 설정 완료 상태여야 함
   (에이전트가 이 런처 폴더의 EXE 와 config.json 토큰을 복사해 씀)
2. `setup_shared_pc.bat` 더블클릭 → 관리자 권한 승인
   1. 원격 데스크톱 켜기 (+방화벽, NLA)
   2. 실무자 계정 생성 — 계정명 쉼표 구분 입력, 비밀번호는 각각 입력
   3. 전원: 충전 중 절전 안 함, 덮개 닫아도 동작
   4. 윈도우 업데이트 사용 시간 08~20시
   5. 종료/다시 시작 = 관리자 계정만 (실무자는 로그아웃·연결 끊기만 — 실수 한 번이 모두의 작업을 끄는 것 방지)
   6. 연결 끊김(X) 상태로 24시간 지난 세션 자동 로그아웃
   7. 세션 에이전트 설치 — 런처 폴더 경로 입력 (예: `C:\Users\James\Downloads\MyriadLauncher`)
3. 허브 → 관리자 → **공용 PC 원격 접속** 에서 윈도우 계정 ↔ 팀원 연결

## 에이전트
- 예약 작업 `MyriadSharedPcAgent` (SYSTEM, 부팅 시 시작) = `MyriadLauncher.exe --shared-pc-agent`
- 파일: `C:\ProgramData\MyriadLauncher\` (agent-bin / agent.json / agent.log) — 관리자·SYSTEM 만 접근 가능
- 30초마다 PC 안에서 세션 확인(네트워크 0), 변경 시 + 15분마다만 허브 보고
- **런처 업데이트 후엔 스크립트 재실행** — 계정 입력은 빈칸 엔터, 7단계에서 `y` (1~6단계는 같은 값 재적용이라 무해)
- 토큰 = 런처 config.json 의 토큰 복사. 그 토큰을 회수하면 에이전트도 멈춤 → 7단계 재실행
